# 🪐 OrbiTask

> **...Tasks in Motion, Goals in Sight**

OrbiTask is a modern task management mobile app built with Flutter — designed to help users crush deadlines, organize projects, and track goals with a clean, intuitive experience.

---

## ✨ Features

- 🚀 **Animated Splash Screens** — Two-phase splash with smooth circle expand animation
- 🎯 **Onboarding Flow** — 4-screen PageView onboarding with dot indicator
- 🔐 **Authentication** — Email/password signup & login, Google Sign-In
- 📅 **Calendar Integration** — View and manage tasks by date
- ⏰ **Time Picker** — Set start time and reminders for tasks
- ✅ **Task Creation** — Multi-step task form with subtasks and file attachments
- 🔔 **Custom Toast Notifications** — Stacked animated toast system
- 🌙 **Light & Dark Theme** — System-aware theme switching
- ⚙️ **Settings Screen** — Profile, notifications, support, and account management
- 📁 **File Attachments** — Attach files to tasks
